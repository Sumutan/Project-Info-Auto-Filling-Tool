项目信息自动填充工具 v1.0
========================


【文件说明】
- 文档格式转换工具.exe：将.doc文件转换为.docx格式
- 项目信息自动填充工具.exe：自动填充项目信息到模板文档
- config.ini：配置文件（可自定义文件夹路径）
- 项目信息示例.txt：项目信息配置示例文件
- 使用说明书.html：详细使用说明书
- 文件模板：存放Word文档模板的文件夹


【快速开始】
1. 将您的Word模板放入"文件模板"文件夹
2. 复制"项目信息示例.txt"并重命名为"项目信息.txt.txt"
3. 编辑"项目信息.txt.txt"填写实际项目信息
4. 运行"文档格式转换工具.exe"转换文档格式
5. 运行"项目信息自动填充工具.exe"填充项目信息
6. 在"输出文件"文件夹中查看处理结果


【详细说明】
请打开"使用说明书.html"查看完整使用说明


【系统要求】
- Windows 7/8/10/11 (64位)
- Microsoft Word 2010 或更高版本
