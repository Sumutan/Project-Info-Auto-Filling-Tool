# 项目信息自动填单工具

!\[项目信息自动填单工具]\(assets/image.png null)

## 功能说明

本工具用于自动填充项目信息到多个Word文档和Excel表格模板中，大幅减少重复填报工作。

## 工具组成

1. `doc_to_docx.py`: 将.doc格式的模板文件批量转换为.docx格式
2. `fill_project_info.py`: 根据项目信息批量替换模板中的字段
3. `项目信息.txt`: 配置项目信息的文件
4. `config.ini`: 自定义路径配置文件（可选）
5. `requirements.txt`: Python依赖清单
6. `release.zip`: 已打包应用程序,解压即可使用(最新发行版本下载链接：<https://pan.quark.cn/s/5a095336e37a>)

## 使用步骤

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

**注意：**

- Windows平台：自动使用pywin32调用Word进行转换
- Mac/Linux平台：需要安装LibreOffice（`brew install libreoffice` 或 `sudo apt install libreoffice`）

### 2. 准备模板文件

将所有需要使用的Word模板文件放在 `文件模板`目录下，可以包含子目录，工具会保持目录结构。

### 3. 转换.doc文件为.docx格式

运行以下命令，将所有.doc文件转换为.docx格式，输出到 `标准化模板`目录：

```bash
python doc_to_docx.py
```

- 转换过程中会保持原有的目录结构
- .docx文件会直接复制到目标目录，无需转换
- 其他非.doc文件（如.xlsx、.xlsm等）也会直接复制到目标目录
- 转换失败的文件会记录并保留原格式

### 4. 自定义路径配置（可选）

如果需要修改默认的文件夹位置，可以编辑 `config.ini`文件：

```ini
[paths]
source_dir = 文件模板          # 原始模板存放目录
template_dir = 标准化模板      # 转换后的模板存放目录
output_dir = 输出文件          # 填充后结果存放目录
project_info_file = 项目信息.txt  # 项目信息配置文件路径
```

不配置的项将使用默认值。

### 5. 配置项目信息

编辑 `项目信息.txt`文件（或config.ini中配置的路径），按照 `字段名: 值`的格式填写项目信息：

```
项目名称:白日梦实现器
合同编号:20262333
采购方式:公开招投标
采购金额:1000000.00
甲方单位:XX科技有限公司
乙方单位:YY软件有限公司
项目负责人:张三
联系电话:13800138000
```

### 5. 批量填充项目信息

运行以下命令，将 `标准化模板`目录下所有.docx和.xlsx/.xlsm文件中的{字段}替换为实际值，结果保存到 `输出文件`目录：

```bash
python fill_project_info.py
```

### Word文档支持：

- 支持替换段落中的字段
- 支持替换表格中的字段
- 字段需要用大括号包裹，如 `{项目名称}`

### Excel表格支持：

- 支持替换所有工作表单元格中的字段
- 支持.xlsx和.xlsm（带宏）格式
- 自动保留Excel原有格式和宏

### 通用特性：

- 不会修改原 `标准化模板`目录中的文件
- 不支持的文件格式会直接复制到输出目录

### 6. 获取结果

填充完成的文件都保存在 `输出文件`目录下，可以直接使用。

## 注意事项

1. 模板中的字段名必须与 `项目信息.txt`中的字段名完全一致，包括大小写
2. 字段必须用大括号 `{}`包裹，如 `{合同编号}`
3. 对于转换失败的.doc文件，可以手动转换为.docx格式后放入 `标准化模板`目录
4. 工具不会修改原 `文件模板`和 `标准化模板`目录中的内容
5. 所有处理结果都保存在 `输出文件`目录中
